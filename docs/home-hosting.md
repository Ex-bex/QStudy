# Домашний хост без VPS

QStudy работает на собственном Windows-компьютере. Для домашней сети используйте **Start-QStudy-LAN.cmd**, для интернета по белому IPv4 и TCP 8080 — **Start-QStudy-Internet.cmd**. Новый запуск автоматически готовит Python и Node.js; Docker и WSL не нужны.

Для доступа извне требуются публичный IPv4, входящий TCP 8080 и проброс порта роутера. Стартер определяет внешний и внутренний адреса, настраивает своё правило Windows Firewall и пробует UPnP. Если автоматическая настройка недоступна, он показывает точное правило. CGNAT одним запуском приложения устранить нельзя: уточните публичный IPv4 у провайдера.

[Полная последовательность без команд](friend-hosting.md). [Перенос аккаунтов, настроек и документов](startup.md). Управление данными и настройками находится в админке.

Компьютер должен оставаться включённым и не засыпать. После перезагрузки снова запустите нужный стартер. Прямой HTTP не шифрует соединение. [Отдельный вариант с доменом и HTTPS](deployment.md).
