QStudy — локальный запуск

1. Запустите Start-QStudy.cmd двойным щелчком.
2. Откройте http://127.0.0.1:3000
3. Для остановки используйте Stop-QStudy.cmd.

Серверы работают в фоне только на этом компьютере. Окно запуска можно закрыть.
После перезагрузки Windows запустите Start-QStudy.cmd повторно.
Данные сохраняются в backend/studyhub.db и backend/uploads.
Ошибки запуска записываются в .local/logs.

Установка зависимостей и ручной запуск описаны в README.md.
