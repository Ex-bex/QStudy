# Обновление действующего Windows-хоста

Обновляйте ту папку QStudy, из которой друг уже запускает сайт. Текущие аккаунты, база, загруженные документы, SMTP, ключ ИИ, логотипы и настройки адреса остаются на его компьютере.

1. Скачайте свежий [Update-QCareer.cmd](https://github.com/Ex-bex/QStudy/raw/refs/heads/main/assets/distribution/Update-QCareer.cmd). Эта кнопка обновляет общую экосистему QStudy, QTests, QCareer, QBall, Q-ID и QControl.
2. Сохраните файл в папку действующего проекта, рядом с `Start-QStudy-Internet.cmd`. Если файл открылся текстом, сохраните его с именем **Update-QCareer.cmd**, выбрав тип **Все файлы**. Включите отображение расширений в Проводнике и проверьте, что имя заканчивается на `.cmd`.
3. Завершите текущие матчи QBall: на время сборки сайт будет остановлен.
4. Дважды щёлкните `Update-QCareer.cmd` от того же пользователя Windows, который запускал сайт. Если появится выбор папки, укажите папку с рабочим стартером.
5. Дождитесь завершения загрузки, проверки пакета и сборки. Скрипт сам остановит эту установку, обновит исходники и снова запустит прежний режим, включая интернет-режим с текущими IP и портом.
6. Откройте прежний адрес сайта и нажмите **Ctrl+F5**. На `/login` и `/register` — вход Q-ID, на `/qcareer` — QCareer, на `/qball` — QBall, на `/qtests` — QTests. Общее управление доступно администратору по `/qcontrol`.

Команды вводить и повторно настраивать роутер при обычном обновлении не требуется. Соединение с GitHub нужно для скачивания обновления; установленные библиотеки используются повторно, а сборка выполняется стартером.

## Какие данные сохраняются

Пакет обновления содержит только исходники и стандартные изображения. Рабочая база, `.env`, личные файлы и загруженные через админку логотипы остаются на месте. Новые поля или таблицы добавляет штатный запуск, без автоматического восстановления старого ZIP. Q-ID использует существующие email и пароли; новый аккаунт для него создавать не требуется.

Полный ZIP в **QControl → Сервер и перенос → Скачать полный ZIP** предназначен для переноса текущего проекта с данными на другой компьютер. Для обновления действующего хоста используйте кнопку выше: так сохраняется именно текущая база этого хоста.

## Если обновление остановилось с ошибкой

Оставьте окно открытым и скопируйте конкретное сообщение об ошибке и несколько строк перед ним. Исправив указанную причину, повторите эту же кнопку. Исходники перед заменой сохраняются в закрытой папке `.local/source-updates`; база из старой копии автоматически не подставляется. Передавайте для диагностики текст ошибки, сохраняя `.env`, пароли и саму базу у владельца хоста.
