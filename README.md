# QStudy

Учебная платформа: группы, расписание с кабинетами, программа по неделям, модульные работы, силабусы с анализом ИИ, заметки, файлы, карточки, тренажёр, тесты, экзаменатор и чат. Администратор управляет общей информацией и аккаунтами; студент — своими материалами, ответами и прогрессом. Права проверяются сервером.

## Четыре файла запуска

Распакуйте проект на Windows x64 в обычную папку, например `C:\QStudy`, и дважды щёлкните нужный файл:

| Файл | Назначение |
| --- | --- |
| **Install-QStudy.cmd** | Проверить среду и установить Python, Node.js и библиотеки |
| **Start-QStudy.cmd** | Запустить сайт на этом компьютере и открыть браузер |
| **Start-QStudy-LAN.cmd** | Запустить сайт для устройств в одной локальной сети |
| **Start-QStudy-Internet.cmd** | Запустить сайт по белому IPv4 и TCP **8080**, определить адрес и подготовить сеть |

Стартеры сами вызывают установку, если это нужно. Отдельно запускать установщик необязательно. Docker, WSL, домен, сертификат и Cloudflare для этих четырёх файлов не требуются. Используется production-сборка Next.js и FastAPI; серверы продолжают работать после закрытия окна.

Во всех режимах используется **одно выбранное существующее хранилище**. Запуск не восстанавливает ZIP, не заменяет базу старой копией и не сбрасывает аккаунты или пароли. SMTP, ключ ИИ, логотипы и учебные данные сохраняются. Если найдены разные прежние базы, выбор нужно сделать один раз: скрипт не угадывает и не объединяет их. Если администратора нет, потребуется создать первый аккаунт; действующий аккаунт стартер не меняет.

Локальный и LAN-режимы подбирают свободный порт начиная с 3000. Интернет использует именно **8080**: если порт занят чужим процессом, запуск сообщает причину. Backend слушает только loopback; наружу открывается сайт.

## Перенос со всеми данными

В админке откройте **«Система» → «Скачать проект со всеми данными»**. Перенесите ZIP на другой компьютер, распакуйте в новую папку и запустите нужный стартер. Архив содержит исходники, согласованный снимок базы, загруженные документы и рабочие настройки. Зависимости устанавливаются на новом компьютере автоматически.

**Этот ZIP приватный:** в нём есть аккаунты, документы и секреты SMTP/ИИ. Передавайте его владельцу сервера напрямую. В GitHub публикуются только исходники; обычный GitHub ZIP текущих аккаунтов и настроек не содержит.

При копировании папки вручную сначала остановите сайт в админке. Переносите код, выбранную базу, uploads и соответствующий `.env`. Обычно это `backend/studyhub.db`, `backend/uploads/`, `backend/.env`; при прежнем контейнерном хранилище сохраняйте также `deployment/data/` и `deployment/.env`. Путь данных показывается в админке. Служебные `.local/`, окружения и `node_modules/` переносить не нужно.

## Управление в админке

Раздел «Система» позволяет скачать полный проект, загрузить ZIP, проверить состав и применить явно выбранную копию. Поддерживаются обычные резервные копии QStudy и полный переносимый проект. Загруженный программный код не выполняется и не заменяет установленное приложение. После импорта войдите заново с аккаунтом и паролем из копии.

Здесь же настраиваются почта, ИИ и общие параметры. Секреты не возвращаются в браузер открытым текстом; пустое поле сохраняет прежнее значение. Перезапуск и остановка доступны при запуске новыми стартерами. Создание и скачивание обычной резервной копии и журнал действий остаются в админке.

Автоматические копии и очередь заданий ИИ сохраняются независимо от режима подключения. Восстановление копии — отдельное действие администратора, а не этап каждого запуска.

## Интернет у друга

На компьютере с белым IP запустите **Start-QStudy-Internet.cmd**. IP определяется автоматически. Windows может запросить разрешение для одного правила QStudy TCP 8080. Стартер попробует UPnP; иначе покажет настоящий LAN-IP компьютера, адрес роутера и точное правило **внешний TCP 8080 → LAN-IP:8080**. Настройка закрытого роутера и провайдера требует доступа владельца.

Проверьте адрес на телефоне через мобильный интернет с выключенным Wi-Fi. Локальная проверка не подтверждает доступ снаружи. CGNAT, второй роутер и блокировка входящих портов требуют настройки сети. HTTP без сертификата не шифрует пароли и документы. [Подробная инструкция](docs/friend-hosting.md).
